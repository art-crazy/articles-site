# Памятка автора

## Перед началом

1. Откройте `/admin`.
2. Создайте новую статью или откройте черновик.
3. Рабочий статус используйте для себя: идея, черновик, на вычитке, готово к публикации.

## Обязательные части статьи

- `Заголовок`: главное название материала.
- `Краткое описание`: 1-2 предложения для списков, поиска и соцсетей.
- `Текст статьи`: основной материал.
- `Адрес страницы`: заполняется автоматически. Если меняете вручную, используйте латинские буквы, цифры и дефисы.

## Желательно заполнить

- `Обложка`: горизонтальное изображение без важного текста по краям.
- `Категория`: главная тема статьи.
- `Теги`: дополнительные темы.
- `Для поисковиков и соцсетей`: можно оставить пустым, если обычный заголовок и описание подходят.

## Перед публикацией

1. Откройте предпросмотр.
2. Проверьте заголовок, обложку, начало текста и изображения.
3. Отметьте чеклист перед публикацией.
4. Публикуйте статью.

## Рекомендуемые статьи внутри текста

В редакторе можно вставить блок `Рекомендуемая статья`. Он покажет читателю ссылку на другой материал прямо внутри текста.

## Бэкап

Перед большой серией правок можно попросить сделать бэкап или выполнить:

```bash
pnpm backup
```

Архив появится в папке `backups/`.
